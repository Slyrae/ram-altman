# Local-only work

Confirm the Codex task host is Local before doing project work or delegating it.
Never substitute a Cloud task for Local execution. Report a Local blocker instead.

# Outgoing email copy

Keep emails to passive-aggressive reporting of the measured RAM and optional VRAM
figures, the message, and the sender's sign-off. End with the sender's name.

Do not add technical disclaimers, explanatory caveats, automation notices,
frequency promises, opt-out/reply footers, or claims about the user's browser tabs,
workload, future idle time, or other unmeasured activity. In particular, never add
the removed snapshot/cache/idle-time/automatically-sent/reply-to-stop wording.

Keep measurement definitions and operational explanations in documentation.
Real email addresses, Google client configuration, tokens and delivery evidence
belong in ignored private files, not the published source.

# Delivery and verification

Never clear the daily delivery journal to force a repeat email. Use isolated test
configuration and a self-addressed test when explicitly authorized. Preserve real
receipts. Passing simulated transport tests does not prove hands-free delivery:
verify the natural scheduled run, Gmail Sent record, later duplicate suppression,
and complete shutdown before claiming the live setup works.
