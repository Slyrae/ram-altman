A personal Windows memory monitor

RamAltman Windows

A small daily report about the memory your PC still has to spare.

When available system RAM is at least 10%, an enabled monitor can send one report per local calendar day from your Google account to your configured recipient.

The monitor runs on your own Windows PC. It samples available physical memory, including reclaimable standby cache, every five minutes while its scheduled task is enabled and your Windows account is logged on. Each email puts the available RAM figure first. Supported NVIDIA GPUs can add a separate snapshot of available VRAM.

These figures describe available capacity at the time of a sample. They do not measure how long RAM has been idle or GPU computing activity.

Google access with a specific purpose

The standalone Gmail option opens your normal browser for Google sign-in and consent. It requests permission to send email and to confirm the Google account's verified email address. It does not request permission to read your inbox, contacts, or existing messages.

  • Your Windows PC sends directly through the Gmail API. The monitor has no hosted application backend.
  • Google authorization tokens are encrypted locally using Windows DPAPI for the Windows user and computer that completed setup.
  • The monitor sends only while enabled and when the RAM threshold qualifies. A durable daily guard prevents duplicate delivery after an uncertain attempt.
  • Disable.cmd turns off delivery, disables the scheduled task, and stops the monitor's owned processes. Saved settings remain available for a later Enable.cmd.
